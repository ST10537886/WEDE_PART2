## Project overview

This project is a responsive five-page website for LizDeLux Botanicals, a South African handmade soap and developing botanical body-care brand. The website presents the business story, current soap collection, product enquiry form, contact form and service areas in Ga-Sekhukhune, Limpopo and Pretoria, Gauteng.

## Website pages

- `index.html` - Home page
- `about.html` - Business history, mission and vision
- `products.html` - Current products and planned categories
- `enquiry.html` - Product and order enquiry form
- `contact.html` - Contact details, service areas and contact form

## Technologies used

- HTML5 for the website structure and content
- CSS3 for the visual design and responsive layout
- CSS Grid and Flexbox for page layouts
- Media queries for desktop, tablet and mobile screens

JavaScript is not connected during Part 2.

## How to run the website

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` with Live Server, or open `index.html` directly in a browser.
4. Use the navigation menu to visit all five pages.
